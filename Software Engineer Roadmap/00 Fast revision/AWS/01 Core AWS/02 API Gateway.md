**API Gateway**

- Front door for APIs.
- Routes requests to backend services.

**Main Uses**

- Routing
- Authentication
- Authorization
- Throttling
- CORS
- Logging

**Authentication**

- Verifies identity.

**Authorization**

- Verifies permissions.

**Throttling**

- Limits request rate.

**CORS**

- Allows browser access from different origins.

**Stages**

- Dev, QA, Prod environments.

**REST API**

- Feature-rich, higher cost.

**HTTP API**

- Faster, cheaper, lower latency.

**Integrates With**

- Lambda
- EC2
- ECS
- External APIs

**Typical Flow**

> Client → API Gateway → Lambda → Database → Response
