# 🚀 60-Second Revision

**RDS**

- Fully managed relational database service.
- Supports SQL Server, MySQL, PostgreSQL, Oracle, and MariaDB.

**Best For**

- Structured business data.
- SQL queries.
- Relationships.
- Transactions.

**AWS Manages**

- Backups.
- Patching.
- Infrastructure.
- High availability.

**You Manage**

- Tables.
- Data.
- SQL queries.
- Schema.

**Multi-AZ**

- High availability with automatic failover.

**Read Replica**

- Improves read performance.

**Backups**

- Automatic backups and manual snapshots.

**RDS vs DynamoDB**

- RDS → SQL, relationships, joins.
- DynamoDB → NoSQL, fast key-based access, no joins.

**Project Example**

- RDS stored structured business data.
- DynamoDB stored statistics.
- S3 stored invoice files.
