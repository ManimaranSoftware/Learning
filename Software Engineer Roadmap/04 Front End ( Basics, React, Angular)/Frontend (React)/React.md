### React

- React - JavaScript library for building user interfaces.
- Component-based architecture.

---

### Component

- Reusable building block of a React application.

---

### JSX

- JavaScript XML syntax used to write UI components.
- Combines JavaScript and HTML-like syntax.

---

### Props

- Read-only data passed from parent to child components.

---

### State

- Stores component-specific data.
- Changes in state trigger UI updates.

---

### Virtual DOM

- Lightweight copy of the Real DOM.
- Improves rendering performance by updating only changed elements.

---

### Hooks

- Functions that allow functional components to use React features.

---

### useState()

- Hook used to manage component state.

---

### useEffect()

- Hook used to perform side effects.
- Examples - API calls, timers, subscriptions.

---

### Conditional Rendering

- Displays UI based on conditions.

---

### Lists & Keys

- Renders collections efficiently.
- Keys uniquely identify list items.

---

### Routing

- Enables navigation between pages.
- Commonly implemented using React Router.

---

### API Calls

- Retrieves data from backend APIs.
- Commonly uses Fetch API or Axios.

---

### Context API

- Shares data across multiple components.
- Reduces prop drilling.

---

### Benefits

- Component reusability.
- Faster UI updates.
- Better maintainability.
- Rich ecosystem.
- Easy integration with REST APIs.
