### DevOps

- DevOps - Culture and practices that improve collaboration between Development and Operations.
- Focuses on automation and continuous delivery.

---

### Continuous Integration (CI)

- Frequently merges code changes into a shared repository.
- Automated builds and tests validate changes.

---

### Continuous Delivery (CD)

- Automatically prepares applications for deployment.
- Deployment to production requires approval.

---

### Continuous Deployment

- Automatically deploys every successful change to production.
- No manual approval required.

---

### Git

- Distributed Version Control System.
- Tracks source code changes.

---

### GitFlow

- Branching strategy for managing development and releases.
- Common Branches - Main, Develop, Feature, Release, Hotfix.

---

### Azure DevOps

- Platform for source control, CI/CD, boards and artifacts.

---

### GitHub Actions

- Workflow automation for build, test and deployment.

---

### Docker

- Containerization platform.
- Packages application and dependencies into containers.

---

### Kubernetes (Basic)

- Container orchestration platform.
- Manages deployment, scaling and availability of containers.

---

### YAML Pipeline

- Pipeline defined using YAML configuration files.
- Used in Azure DevOps and GitHub Actions.

---

### Infrastructure as Code (IaC)

- Infrastructure managed using configuration files.
- Examples - CloudFormation, Terraform.

---

### Artifact

- Deployable output generated during the build process.
- Example - DLL, Docker Image, ZIP Package.

---

### Deployment Strategies

- Blue-Green Deployment
- Rolling Deployment
- Canary Deployment

---

### Rollback

- Restores the previous stable application version after deployment failure.

---

### Monitoring

- Continuously tracks application health and performance.

---

### Logging

- Records application events and errors for troubleshooting.

---

### Benefits

- Faster software delivery.
- Automated deployments.
- Better collaboration.
- Improved reliability.
- Reduced manual effort.
