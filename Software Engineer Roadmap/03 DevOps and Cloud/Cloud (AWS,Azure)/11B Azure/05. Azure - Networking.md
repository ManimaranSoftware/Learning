## Topics

- Virtual Network (VNet)
- Subnet
- Network Security Group (NSG)
- Load Balancer
- Application Gateway
- VPN Gateway
- DNS

---

# Virtual Network (VNet)

- Private network in Azure.
- Enables secure communication between Azure resources.
- Can connect to on-premises networks.
- Supports Subnets.
- AWS Equivalent: VPC.
- Example: Connect App Service, VM and SQL Database securely.
- Interview: VNet isolates resources from the public internet.

---

# Subnet

- Logical division of a VNet.
- Organizes resources into smaller networks.
- Improves security and management.
- AWS Equivalent: Subnet.
- Example: Separate Web, API and Database into different subnets.

---

# Network Security Group (NSG)

- Controls inbound and outbound traffic.
- Uses Allow/Deny rules.
- Applied to Subnets or Network Interfaces.
- AWS Equivalent: Security Group.
- Example: Allow HTTP (80) and HTTPS (443), Block others.
- Interview: Firewall for Azure resources.

---

# Load Balancer

- Distributes incoming traffic across multiple servers.
- Improves availability and scalability.
- Supports Layer 4 (TCP/UDP).
- AWS Equivalent: Elastic Load Balancer (NLB).
- Example: Balance traffic across multiple Virtual Machines.

---

# Application Gateway

- Layer 7 Load Balancer.
- Supports HTTP/HTTPS routing.
- Provides SSL Termination and Web Application Firewall (WAF).
- AWS Equivalent: Application Load Balancer (ALB).
- Example: Route `/api` to API Server and `/web` to Web Server.
- Interview: Used for web applications.

---

# VPN Gateway

- Connects Azure VNet with on-premises networks.
- Provides encrypted communication.
- Supports Site-to-Site and Point-to-Site VPN.
- AWS Equivalent: AWS VPN Gateway.
- Example: Connect company office to Azure.

---

# Azure DNS

- Managed DNS hosting service.
- Translates domain names into IP addresses.
- Highly available and globally distributed.
- AWS Equivalent: Route 53.
- Example: `api.company.com → Azure App Service`

---

## Difference

|Service|Purpose|
|---|---|
|VNet|Private Network|
|Subnet|Divide VNet|
|NSG|Firewall Rules|
|Load Balancer|Layer 4 Traffic Distribution|
|Application Gateway|Layer 7 Routing + WAF|
|VPN Gateway|Connect On-Premises|
|Azure DNS|Domain Name Resolution|
