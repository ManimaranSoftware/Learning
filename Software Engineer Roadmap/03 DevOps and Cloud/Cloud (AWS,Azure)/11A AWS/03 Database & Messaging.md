### Amazon RDS

- RDS (Relational Database Service) - Managed relational database service.
- Supports SQL Server, MySQL, PostgreSQL, Oracle and MariaDB.

---

### Amazon DynamoDB

- DynamoDB - Fully managed NoSQL database.
- High performance and automatic scaling.

---

### Amazon ElastiCache

- Managed caching service.
- Supports Redis and Memcached.

---

### Amazon SQS

- SQS (Simple Queue Service) - Fully managed message queue service.
- Supports asynchronous communication.

---

### Amazon SNS

- SNS (Simple Notification Service) - Publish/Subscribe messaging service.
- Delivers messages to multiple subscribers.

---

### Amazon EventBridge

- Event bus service.
- Routes events between AWS services and applications.

---

### AWS Glue

- Serverless ETL service.
- Extracts, transforms and loads data.
- Used for data integration and analytics.

---

### Amazon API Gateway

- Managed service for creating, publishing and securing APIs.
- Commonly used with AWS Lambda.

---

### Use Cases

- **RDS** → Relational databases.
- **DynamoDB** → NoSQL applications.
- **ElastiCache** → Caching with Redis/Memcached.
- **SQS** → Message queues.
- **SNS** → Notifications and Pub/Sub.
- **EventBridge** → Event routing.
- **Glue** → ETL and data processing.
- **API Gateway** → API management.

---

### Benefits

- Managed database services.
- Reliable messaging.
- High scalability.
- Reduced operational overhead.
- Easy service integration.
