### Cloud Computing

- Cloud Computing - Delivery of computing resources over the internet.
- Provides on-demand infrastructure and services.

---

### AWS

- AWS (Amazon Web Services) - Cloud platform providing infrastructure and managed services.

---

### Region

- Region - Physical geographic location containing multiple Availability Zones.

---

### Availability Zone (AZ)

- Availability Zone - Isolated data center within a Region.
- Improves fault tolerance and high availability.

---

### Edge Location

- Edge Location - Used by CloudFront to deliver content closer to users.

---

### Global Infrastructure

- Consists of Regions, Availability Zones and Edge Locations.

---

### High Availability

- Application remains available even if one Availability Zone fails.

---

### Scalability

- Ability to increase or decrease resources based on demand.

---

### Elasticity

- Automatically adjusts resources according to workload.

---

### Shared Responsibility Model

- AWS - Responsible for security **of** the cloud.
- Customer - Responsible for security **in** the cloud.

---

### Pay-as-you-Go

- Pay only for the resources you use.

---

### Benefits

- High availability.
- Scalability.
- Global infrastructure.
- Cost optimization.
- Managed services.
