### Design Pattern

- Design Pattern - Reusable solution to a commonly occurring software design problem.
- Improves code quality, maintainability and reusability.

---

### GoF (Gang of Four)

- Authors who introduced the 23 classic Design Patterns.
- Patterns are grouped into Creational, Structural and Behavioral.

---

### Creational Pattern

- Focuses on object creation.
- Makes object creation flexible and reusable.

---

### Structural Pattern

- Focuses on how classes and objects are organized.
- Improves relationships between components.

---

### Behavioral Pattern

- Focuses on communication and interaction between objects.

---

### Enterprise Pattern

- Solves common enterprise application problems.
- Examples - Repository, Unit of Work, Dependency Injection.

---

### Distributed System Pattern

- Solves problems in distributed applications.
- Examples - Retry, Circuit Breaker, Saga, Outbox.

---

### Composition over Inheritance

- Prefer combining objects instead of inheriting behavior.
- Provides greater flexibility.

---

### Loose Coupling

- Components have minimal dependency on each other.
- Easier to modify and test.

---

### High Cohesion

- Related functionality stays together.
- Improves maintainability.

---

### SOLID Principles

- Foundation for many Design Patterns.
- Encourages clean and extensible design.

---

### Benefits

- Reusable solutions.
- Better maintainability.
- Easier testing.
- Flexible architecture.
- Improved code readability.
