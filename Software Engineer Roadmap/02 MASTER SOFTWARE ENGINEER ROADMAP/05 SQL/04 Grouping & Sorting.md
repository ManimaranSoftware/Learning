### GROUP BY

- GROUP BY - Groups rows with the same values into summary rows.
- Commonly used with Aggregate Functions.

---

### HAVING

- HAVING - Filters grouped data.
- Used after `GROUP BY`.

---

### WHERE

- WHERE - Filters rows before grouping.
- Cannot use aggregate functions directly.

---

### ORDER BY

- ORDER BY - Sorts query results.
- Default - Ascending (`ASC`).

---

### ASC

- Sorts data in ascending order.

---

### DESC

- Sorts data in descending order.

---

### DISTINCT

- Returns unique values.
- Removes duplicate records from the result.

---

### TOP

- Returns specified number of rows.
- SQL Server specific.

---

### OFFSET

- Skips specified number of rows.
- Commonly used with pagination.

---

### FETCH

- Retrieves specified number of rows after `OFFSET`.
- Used for pagination.

---
### Alias

- Column Alias - Temporary name for a column.
- Table Alias - Temporary name for a table.
- Improves query readability.
---

### Benefits

- Data summarization.
- Efficient filtering.
- Ordered results.
- Pagination support.
