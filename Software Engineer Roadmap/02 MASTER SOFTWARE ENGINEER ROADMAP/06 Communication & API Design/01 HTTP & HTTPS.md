### HTTP

- HTTP (HyperText Transfer Protocol) - Communication protocol between client and server.
- Stateless protocol.
- Application Layer protocol.

---

### HTTPS

- HTTPS - Secure version of HTTP.
- Uses SSL/TLS encryption.
- Protects data during transmission.

---

### Request

- HTTP Request - Sent by client to the server.
- Contains Method, URL, Headers and Body.

---

### Response

- HTTP Response - Returned by the server.
- Contains Status Code, Headers and Body.

---

### URL

- URL - Address used to access a resource.

---

### URI

- URI - Identifier of a resource.
- URL is a type of URI.

---

### HTTP Headers

- Carry metadata between client and server.
- Examples - Authorization, Content-Type, Accept.

---

### Request Body

- Contains data sent to the server.
- Commonly used with POST, PUT and PATCH.

---

### Response Body

- Contains data returned by the server.
- Usually JSON in REST APIs.

---

### MIME Type

- Specifies the data format.
- Examples - `application/json`, `application/xml`, `text/html`.

---

### Stateless

- Server does not store client session between requests.
- Every request contains all required information.

---

### SSL/TLS

- Encrypts communication between client and server.
- Used by HTTPS.

---

### Benefits

- Standard communication protocol.
- Platform independent.
- Secure communication with HTTPS.
- Supports RESTful APIs.

---

### HTTP Session

- Session - Server-side storage of user data.
- Commonly used in traditional web applications.
- REST APIs generally prefer stateless authentication using JWT.
