### Database

- Database - Organized collection of related data.

---

### DBMS

- DBMS - Software used to create and manage databases.

---

### RDBMS

- RDBMS - Relational Database Management System.
- Stores data in tables.
- Supports relationships using keys.

---

### Table

- Table - Collection of rows and columns.

---

### Row

- Row (Record) - Represents a single data entry.

---

### Column

- Column - Represents an attribute of the data.

---

### Primary Key

- Primary Key - Uniquely identifies each row.
- Cannot contain `NULL`.
- Must be unique.

---

### Foreign Key

- Foreign Key - Establishes relationship between tables.
- References a Primary Key.

---

### Candidate Key

- Candidate Key - Column(s) that can uniquely identify a row.

---

### Alternate Key

- Alternate Key - Candidate Key not selected as Primary Key.

---

### Composite Key

- Composite Key - Combination of multiple columns forming a unique key.

---

### Unique Key

- Unique Key - Ensures unique values.
- Allows `NULL` (DBMS-dependent).

---

### NULL

- NULL - Represents missing or unknown value.
- Different from `0` or empty string.

---

### Constraints

- NOT NULL - Prevents `NULL` values.
- UNIQUE - Ensures unique values. - null allowed
- PRIMARY KEY - Uniquely identifies rows.
- FOREIGN KEY - Maintains referential integrity.
- CHECK - Restricts allowed values.
- DEFAULT - Assigns default value.

---

### Data Types

- INT - Integer values.
- BIGINT - Large integer values.
- DECIMAL - Fixed precision numeric values.
- FLOAT - Approximate numeric values.
- CHAR - Fixed-length string.
- VARCHAR - Variable-length string.
- DATE - Date only.
- DATETIME - Date and time.
- BIT - Boolean-like value.

---

### CRUD

- CREATE - Create objects.
- INSERT - Add records.
- SELECT - Retrieve records.
- UPDATE - Modify records.
- DELETE - Remove records.

---

### Benefits

- Organized data storage.
- Data integrity.
- Relationship support.
- Efficient querying.
