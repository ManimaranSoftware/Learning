### Creational Pattern

- Creational Pattern - Focuses on object creation.
- Makes object creation flexible and reusable.

---

### Singleton

- Ensures only one instance of a class exists.
- Provides a global access point.
- Common Example - Logger, Configuration.

---

### Factory Method

- Creates objects without exposing the creation logic.
- Returns objects through a common interface.

---

### Abstract Factory

- Creates families of related objects.
- Useful when multiple related objects must be created together.

---

### Builder

- Creates complex objects step by step.
- Separates object construction from representation.

---

### Prototype

- Creates new objects by cloning existing objects.
- Useful when object creation is expensive.

---

### Object Creation

- Encapsulates object creation logic.
- Reduces direct dependency on concrete classes.

---

### Benefits

- Loose coupling.
- Flexible object creation.
- Better maintainability.
- Improved scalability.
- Easier testing.
