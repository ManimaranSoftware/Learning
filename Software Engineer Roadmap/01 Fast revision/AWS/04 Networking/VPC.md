> **VPC → Private Network → Public Subnet → Private Subnet → Security Group**

---

# 60-Second Revision

- VPC is a private network in AWS.
- Used for secure networking.
- Public subnet is internet accessible.
- Private subnet is internal only.
- Security Groups act as virtual firewalls. 
		Allow
			HTTP (80)
			HTTPS (443)
			SQL (1433)
- Commonly used with EC2, RDS, and Lambda.
