# 60-Second Revision

**CloudWatch**

- Monitoring and logging service.

**Logs**

- Stores application and Lambda logs.
- Used for debugging.

**Metrics**

- Numeric performance data.
- Example: CPU, Errors, Invocations, Duration.

**Alarms**

- Trigger notifications when thresholds are exceeded.

**Dashboards**

- Visualize application and infrastructure metrics.

**Common Integration**

- Lambda → CloudWatch Logs
- API Gateway → CloudWatch Metrics
- EC2 → CloudWatch Metrics

**Project Example**

- Used CloudWatch to monitor Lambda execution, inspect logs, and troubleshoot issues.
