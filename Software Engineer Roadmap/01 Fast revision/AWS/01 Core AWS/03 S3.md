# 60-Second Revision

**S3**

- Object storage service.
- Stores files like PDFs, images, videos, logs, backups.

**Bucket**

- Logical container for objects.

**Object**

- File stored in S3.

**Object Key**

- Unique file path within a bucket.

**Versioning**

- Keeps multiple versions of a file.

**Storage Classes**

- Standard
- Intelligent-Tiering
- Standard-IA
- Glacier
- Glacier Deep Archive

**Lifecycle Rules**

- Automatically move or delete files based on age.

**Pre-Signed URL**

- Temporary secure access to private files.

**Bucket Policy**

- Controls who can access the bucket.

**Encryption**

- S3 supports encryption to protect data.
Common types: SSE-S3, SSE-KMS, Client-side encryption
Sensitive data stored in S3 should be encrypted.

**Common Flow**

> Application/Lambda → Upload to S3 → Store → Retrieve using Pre-Signed URL or SDK
