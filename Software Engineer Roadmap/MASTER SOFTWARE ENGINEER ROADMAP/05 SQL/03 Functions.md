### SQL Function

- SQL Function - Performs an operation and returns a value.

---

### Scalar Function

- Returns a single value.
- Processes one row at a time.

---

### Aggregate Function

- Performs calculation on multiple rows.
- Returns a single result.

---

### COUNT()

- Returns the number of rows.

---

### SUM()

- Returns the total of numeric values.

---

### AVG()

- Returns the average of numeric values.

---

### MIN()

- Returns the smallest value.

---

### MAX()

- Returns the largest value.

---

### String Functions

- UPPER() - Converts text to uppercase.
- LOWER() - Converts text to lowercase.
- LEN() - Returns string length.
- TRIM() - Removes leading and trailing spaces.
- SUBSTRING() - Returns part of a string.
- REPLACE() - Replaces text.
- CONCAT() - Combines strings.

---

### Date Functions

- GETDATE() - Returns current date and time.
- DATEADD() - Adds date interval.
- DATEDIFF() - Returns difference between dates.
- YEAR() - Returns year.
- MONTH() - Returns month.
- DAY() - Returns day.

---

### NULL Functions

- ISNULL() - Replaces NULL with specified value.
- COALESCE() - Returns first non-NULL value.

---

### Conversion Functions

- CAST() - Converts one data type to another.
- CONVERT() - Converts data type with formatting options.

---

### Mathematical Functions

- ROUND() - Rounds numeric value.
- CEILING() - Returns next highest integer.
- FLOOR() - Returns next lowest integer.
- ABS() - Returns absolute value.

---
### User Defined Function (UDF)

- User Defined Function - Custom function created by users.
- Types - Scalar Function, Table-Valued Function.

---

### Benefits

- Reusable calculations.
- Cleaner queries.
- Simplifies data manipulation.
- Improves readability.
