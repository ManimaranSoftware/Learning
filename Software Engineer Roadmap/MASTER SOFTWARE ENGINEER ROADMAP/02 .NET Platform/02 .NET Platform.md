## .NET Framework ⭐⭐⭐⭐⭐

- .NET Framework - Original .NET implementation, Windows-only.
- Runtime - Uses CLR (Common Language Runtime).
- Applications - ASP.NET MVC, Web API, WPF, WinForms, WCF.
- Latest Version - 4.8.1.
- Status - Maintenance mode, No new major features.

---

## .NET Core ⭐⭐⭐⭐⭐

- .NET Core - Cross-platform implementation of .NET.
- Platforms - Windows, Linux, macOS.
- Performance - Faster and lightweight than .NET Framework.
- Applications - Web API, MVC, Console, Microservices, Cloud.
- Status - Foundation for modern .NET.

---

## .NET 5 / 6 / 7 / 8 ⭐⭐⭐⭐⭐

- .NET 5 - Unified platform replacing separate .NET implementations.
- .NET 6 - LTS (Long Term Support), Widely adopted.
- .NET 7 - STS (Standard Term Support), Performance improvements.
- .NET 8 - LTS, Current modern .NET version, Better performance, Native AOT, Cloud optimizations.

---

## CLR (Common Language Runtime) ⭐⭐⭐⭐⭐

- CLR - Execution engine of .NET applications.
- Responsibilities - JIT Compilation, Garbage Collection, Memory Management, Exception Handling, Thread Management, Security.

---

## CTS (Common Type System) ⭐⭐⭐⭐

- CTS - Defines all data types supported by .NET.
- Purpose - Enables language interoperability.
- Categories - Value Types and Reference Types.

---

## CLS (Common Language Specification) ⭐⭐⭐⭐

- CLS - Subset of CTS.
- Purpose - Defines rules for language interoperability.
- Benefit - Code written in one .NET language can be used by another.

---

## IL (Intermediate Language) ⭐⭐⭐⭐⭐

- IL - CPU-independent intermediate code generated by the compiler.
- Stored In - Assemblies (.dll / .exe).
- Executed By - JIT Compiler.

---

## JIT (Just-In-Time Compiler) ⭐⭐⭐⭐⭐

- JIT - Converts IL into Native Machine Code.
- Executes - At runtime.
- Types - Normal JIT, Pre-JIT, Econo JIT (legacy).

---

## Assemblies ⭐⭐⭐⭐⭐

- Assembly - Deployment unit of .NET applications.
- Types - DLL and EXE.
- Contains - IL, Metadata, Manifest and Resources.

---

## Metadata ⭐⭐⭐⭐

- Metadata - Information about types, methods, properties and assemblies.
- Used By - CLR and Reflection.

---

## Manifest ⭐⭐⭐⭐

- Manifest - Describes assembly information.
- Contains - Assembly name, Version, Culture, Dependencies.

---

## NuGet ⭐⭐⭐⭐⭐

- NuGet - Package manager for .NET.
- Purpose - Installs and manages third-party libraries.
- Repository - nuget.org.

---

## SDK ⭐⭐⭐⭐⭐

- SDK - Software Development Kit for building .NET applications.
- Includes - Compiler, CLI, Templates, Libraries and Runtime (or references to it depending on installation).

---

## Runtime ⭐⭐⭐⭐⭐

- Runtime - Required to run .NET applications.
- Executes - Compiled .NET applications.
- Does not include development tools.

---

## CLI (.NET Command Line Interface) ⭐⭐⭐⭐

- CLI - Command-line tool for .NET development.
- Common Commands - `dotnet new`, `dotnet build`, `dotnet run`, `dotnet publish`, `dotnet test`.

---

## Benefits

- Cross-platform development.
- High performance.
- Automatic memory management.
- Rich ecosystem.
- Strong tooling support.
