### ASP.NET

- ASP.NET - Microsoft's framework for building web applications and APIs.
- Types - Web Forms, MVC, Web API.

---

### ASP.NET Core

- ASP.NET Core - Cross-platform framework for building modern web applications and REST APIs.
- Platforms - Windows, Linux, macOS.
- High Performance - Lightweight and optimized.
- Built on - Modern .NET (.NET Core / .NET 5+).

---

### MVC

- MVC - Model View Controller architecture.
- Model - Business logic and data.
- View - User Interface.
- Controller - Handles requests and responses.

---

### Web API

- Web API - Framework for building RESTful HTTP services.
- Returns - JSON/XML instead of Views.
- Used by - Web, Mobile and Third-party applications.

---

### Minimal API

- Minimal API - Lightweight approach to build APIs with minimal configuration.
- Introduced - .NET 6.
- Suitable for - Small APIs and Microservices.

---

### Program.cs

- Entry point of ASP.NET Core application.
- Configures Services and Middleware.
- Builds and runs the application.

---

### WebApplicationBuilder

- Creates and configures the application.
- Registers services into Dependency Injection container.

---

### appsettings.json

- Stores application configuration.
- Examples - Connection Strings, JWT, Logging.

---

### launchSettings.json

- Development-only configuration.
- Defines URLs, Profiles and Environment Variables.

---

### Kestrel

- Cross-platform web server for ASP.NET Core.
- Default web server.
- Can run standalone or behind IIS/Nginx.

---

### IIS

- Windows web server.
- Often used as Reverse Proxy for Kestrel.

---

### Environment

- Defines application environment.
- Common Values - Development, Staging, Production.

---

### Benefits

- Cross-platform
- High Performance
- Built-in Dependency Injection
- Middleware Pipeline
- Cloud Ready
- Open Source
