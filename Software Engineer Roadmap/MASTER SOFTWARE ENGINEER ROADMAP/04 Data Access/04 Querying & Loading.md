### Querying

- Querying - Retrieving data from the database using LINQ or SQL.
- EF Core translates LINQ queries into SQL.

---

### LINQ to Entities

- Executes queries against the database.
- SQL generated by EF Core.

---

### Filtering

- Retrieves records based on conditions.
- Common Method - `Where()`.

---

### Sorting

- Orders query results.
- Common Methods - `OrderBy()`, `OrderByDescending()`.

---

### Projection

- Selects specific columns instead of entire entity.
- Common Method - `Select()`.

---

### Pagination

- Retrieves data in pages.
- Common Methods - `Skip()` and `Take()`.

---

### Include()

- Eagerly loads related entities.
- Reduces additional database queries.

---

### ThenInclude()

- Loads nested related entities.
- Used after `Include()`.

---

### Eager Loading

- Loads related data together with the main entity.
- Uses `Include()`.

---

### Lazy Loading

- Loads related data only when accessed.
- Requires Lazy Loading support.

---

### Explicit Loading

- Related data loaded manually when required.
- Provides better control than Lazy Loading.

---

### Loading Strategy

- Determines how related data is retrieved.
- Types - Eager, Lazy and Explicit Loading.

---

### Global Query Filter 

- Automatically applies filter to every query. 
- Commonly used for Soft Delete and Multi-tenancy.

---
### AsNoTracking()

- Retrieves entities without change tracking.
- Improves read-only query performance.

---

### Benefits

- Efficient data retrieval.
- Optimized database queries.
- Flexible loading strategies.
- Better read performance.
