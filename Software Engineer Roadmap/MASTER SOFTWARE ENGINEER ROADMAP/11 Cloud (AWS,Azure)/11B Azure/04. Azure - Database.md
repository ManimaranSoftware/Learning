## Topics

- Azure SQL Database
- SQL Managed Instance
- Cosmos DB
- Azure Cache for Redis

---

# Azure SQL Database

- Fully managed relational database service (PaaS).
- Based on Microsoft SQL Server.
- Azure manages backups, patching, updates and scaling.
- Supports T-SQL, Stored Procedures and Indexes.
- AWS Equivalent: Amazon RDS (SQL Server).
- Example: Employee Management System.
- Interview: Choose when using SQL Server without managing infrastructure.

---

# SQL Managed Instance

- Managed SQL Server with near 100% SQL Server compatibility.
- Supports SQL Agent, Linked Servers and Cross Database Queries.
- Easier migration from on-premises SQL Server.
- AWS Equivalent: Amazon RDS for SQL Server (closest).
- Example: Lift-and-shift migration.

---

# Cosmos DB

- Globally distributed NoSQL database.
- Supports multiple data models (Document, Key-Value, Graph, Column).
- Low latency with automatic replication.
- Supports multiple APIs (SQL, MongoDB, Cassandra, Gremlin).
- AWS Equivalent: DynamoDB.
- Example: Shopping Cart, User Profile.
- Interview: Best for globally distributed NoSQL applications.

---

# Azure Cache for Redis

- In-memory cache.
- Improves application performance.
- Reduces database calls.
- Stores frequently accessed data.
- AWS Equivalent: Amazon ElastiCache (Redis).
- Example: Product Catalog Cache.
- Interview: Used to improve performance and reduce database load.

---

## Difference

|Service|Purpose|
|---|---|
|Azure SQL|Relational Database|
|SQL Managed Instance|SQL Server Migration|
|Cosmos DB|NoSQL Database|
|Redis|In-Memory Cache|
