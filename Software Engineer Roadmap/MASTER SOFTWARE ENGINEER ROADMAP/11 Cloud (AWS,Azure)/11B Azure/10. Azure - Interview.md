# High Availability (HA)

- Ensures applications remain available even during failures.
- Achieved using Availability Zones, Load Balancer and VM Scale Sets.
- Reduces downtime.
- AWS Equivalent: Multi-AZ Deployment.
- Interview: Keeps applications running during hardware or data center failures.

---

# Scalability

- Ability to handle increasing workload.
- **Vertical Scaling** → Increase CPU/RAM.
- **Horizontal Scaling** → Add more instances.
- Azure supports Auto Scaling.
- AWS Equivalent: Auto Scaling.
- Interview: Horizontal scaling is preferred for cloud applications.

---

# Disaster Recovery (DR)

- Restores applications after major failures.
- Uses Region Pairs and Backup Services.
- Protects business continuity.
- AWS Equivalent: Multi-Region Disaster Recovery.
- Interview: HA minimizes downtime, DR restores services after disasters.

# Common Interview Questions

### Why App Service instead of Virtual Machine?

- No server management.
- Automatic scaling.
- Faster deployment.
- Lower maintenance.

---

### App Service vs Azure Functions

|App Service|Azure Functions|
|---|---|
|Long-running applications|Event-driven execution|
|APIs & Websites|Background tasks|
|Always running|Runs only when triggered|

---

### Service Bus vs Event Grid

|Service Bus|Event Grid|
|---|---|
|Reliable Messaging|Event Routing|
|Queue & Topics|Publish/Subscribe|
|Microservices|Event-driven Architecture|

---

### Blob Storage vs Azure Files

|Blob Storage|Azure Files|
|---|---|
|Object Storage|File Share|
|Images, PDFs, Videos|Shared Folder|
|Access via HTTP|Access via SMB|

---

### Azure SQL vs Cosmos DB

|Azure SQL|Cosmos DB|
|---|---|
|Relational|NoSQL|
|Structured Data|Semi/Unstructured Data|
|SQL Queries|Document Database|

---

### VM vs App Service vs AKS

|VM|App Service|AKS|
|---|---|---|
|Full Server Control|Host Web Apps|Container Orchestration|
