# Azure Monitor

- Centralized monitoring service for Azure resources.
- Collects Metrics, Logs and Diagnostic Data.
- Monitors application and infrastructure health.
- Supports Dashboards and Alerts.
- AWS Equivalent: Amazon CloudWatch.
- Example: Monitor CPU, Memory and Disk usage of a VM.
- Interview: Used for monitoring Azure resources.

---

# Application Insights

- Application Performance Monitoring (APM) service.
- Monitors application performance and failures.
- Tracks Requests, Exceptions, Dependencies and Response Time.
- Helps identify bottlenecks.
- AWS Equivalent: CloudWatch + AWS X-Ray.
- Example: Identify slow API response times.
- Interview: Used to monitor ASP.NET Core applications.

---

# Log Analytics

- Stores and analyzes logs from Azure resources.
- Uses Kusto Query Language (KQL) for querying.
- Integrates with Azure Monitor.
- AWS Equivalent: CloudWatch Logs Insights.
- Example: Search application errors across multiple servers.

---

# Alerts

- Sends notifications when a condition is met.
- Can notify via Email, SMS or Webhook.
- Based on Metrics or Logs.
- AWS Equivalent: CloudWatch Alarms.
- Example: Notify when CPU usage exceeds 80%.

---

# Metrics

- Numerical performance data collected over time.
- Examples: CPU Usage, Memory Usage, Request Count, Response Time.
- Used for monitoring and alerting.
- AWS Equivalent: CloudWatch Metrics.
