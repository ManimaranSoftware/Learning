# Azure DevOps

- End-to-end DevOps platform.
- Supports Planning, Source Control, CI/CD and Testing.
- Includes Repos, Pipelines, Boards, Test Plans and Artifacts.
- AWS Equivalent: CodeCommit + CodeBuild + CodePipeline.
- Example: Build and deploy ASP.NET Core applications.
- Interview: Used for CI/CD automation.

---

# Azure Repos

- Git repository hosting service.
- Supports Git and TFVC.
- Used for source code management.
- AWS Equivalent: CodeCommit.
- Example: Store ASP.NET Core project source code.

---

# Azure Pipelines

- CI/CD service.
- Automatically builds, tests and deploys applications.
- Supports YAML and Classic Pipelines.
- Integrates with GitHub and Azure Repos.
- AWS Equivalent: CodePipeline + CodeBuild.
- Example: Deploy Web API after every Git commit.
- Interview: Used to automate deployments.

---

# ARM Templates

- Infrastructure as Code (IaC) using JSON.
- Automates Azure resource deployment.
- Ensures consistent deployments.
- AWS Equivalent: CloudFormation.
- Example: Create VM, Storage and SQL Database together.

---

# Bicep

- Simplified language for ARM Templates.
- Easier to read and write.
- Compiles into ARM Templates.
- AWS Equivalent: AWS CDK (conceptually).
- Example: Deploy Azure infrastructure with less code.

---

# Docker

- Containerization platform.
- Packages application with dependencies.
- Ensures consistency across environments.
- AWS Equivalent: Docker (same technology).
- Example: Package ASP.NET Core API into a container.
- Interview: "Build once, run anywhere."

---

# Azure Container Registry (ACR)

- Private Docker image repository.
- Stores container images securely.
- Integrates with AKS.
- AWS Equivalent: Amazon ECR.
- Example: Store ASP.NET Core Docker images.

---

# AKS Deployment

- Deploy Docker containers to Azure Kubernetes Service.
- Supports Auto Scaling and Rolling Updates.
- Uses images stored in ACR.
- AWS Equivalent: Amazon EKS Deployment.
- Example: Deploy Microservices.
