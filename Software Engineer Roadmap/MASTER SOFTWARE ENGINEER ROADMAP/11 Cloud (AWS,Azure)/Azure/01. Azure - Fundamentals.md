# Azure Overview

- Microsoft Azure is Microsoft's cloud computing platform.
- Provides on-demand computing resources over the internet.
- Supports IaaS, PaaS, and SaaS.
- Used to build, deploy, and manage applications.
- Pay-as-you-go pricing.
- AWS Equivalent: AWS.
- Example: Host an ASP.NET Core Web API.

---

# Cloud Computing

- Delivery of computing services over the internet.
- No need to own physical servers.
- Resources include Compute, Storage, Networking and Databases.
- Highly scalable and highly available.
- Examples: Azure, AWS, GCP.

---

# Service Models (IaaS, PaaS, SaaS)

**IaaS**

- Azure manages hardware.
- You manage OS, Runtime and Application.
- Example: Virtual Machine.
- AWS Equivalent: EC2.

**PaaS**

- Azure manages hardware, OS and Runtime.
- You only deploy code.
- Example: App Service, Azure Functions.
- AWS Equivalent: Elastic Beanstalk, Lambda.

**SaaS**

- Complete software delivered over the internet.
- Example: Microsoft 365, Outlook, Teams.

---

# Azure Global Infrastructure

- Worldwide network of Azure data centers.
- Built using Regions and Availability Zones.
- Provides High Availability and Disaster Recovery.
- Improves application performance by deploying closer to users.

---

# Regions

- Geographic locations containing one or more Azure data centers.
- Choose the nearest region for low latency.
- Example: Central India, South India.
- AWS Equivalent: AWS Region.

---

# Availability Zones

- Physically separate data centers within the same region.
- Independent power, cooling and networking.
- Protects applications from data center failure.
- AWS Equivalent: Availability Zone (AZ).

---

# Region Pairs

- Every Azure region has a paired region.
- Used for Disaster Recovery.
- Microsoft prioritizes recovery of paired regions.
- Example: South India ↔ Central India.

---

# Resource Groups

- Logical container for Azure resources.
- Groups related resources together.
- Resources can be managed and deleted together.
- A resource belongs to only one Resource Group.
- AWS Equivalent: AWS Resource Groups (closest).

---

# Azure Resource Manager (ARM)

- Azure deployment and management service.
- Creates, updates and deletes Azure resources.
- Supports Infrastructure as Code using ARM Templates.
- AWS Equivalent: CloudFormation.

---

# Subscription

- Billing and management boundary in Azure.
- Every Azure resource belongs to one subscription.
- Used to track costs, permissions and quotas.
- Similar to an AWS Account.

---

# Azure Portal

- Web-based GUI for managing Azure resources.
- Used to create, monitor and manage services.
- Good for beginners and administrators.

---

# Azure CLI

- Command-line tool for managing Azure.
- Supports Windows, Linux and macOS.
- Used for automation and scripting.
- AWS Equivalent: AWS CLI.

Example:

```
az group create --name DemoRG --location centralindia
```

---

# Azure PowerShell

- PowerShell module for Azure management.
- Used mainly by Windows administrators.
- Automates Azure tasks using PowerShell scripts.

Example:

```
New-AzResourceGroup -Name DemoRG -Location "Central India"
```
