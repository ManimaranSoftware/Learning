---

# Storage Account

- Primary Azure storage resource.
- Stores Blob, Queue, Table and File services.
- Required before creating any storage service.
- Supports Standard and Premium performance.
- AWS Equivalent: Storage Services (S3 + EFS + SQS under one storage account concept).

---

# Blob Storage

- Stores unstructured data.
- Used for images, videos, PDFs, backups and documents.
- Supports public/private access.
- Supports lifecycle management.
- AWS Equivalent: Amazon S3.
- Example: Store invoice PDFs.

---

# Queue Storage

- Stores messages between applications.
- Supports asynchronous communication.
- Simple message queue service.
- Maximum message size: 64 KB.
- AWS Equivalent: Amazon SQS.
- Example: Order Processing Queue.
- Interview: Used to decouple applications.

---

# Table Storage

- NoSQL Key-Value database.
- Stores structured, non-relational data.
- Highly scalable and cost-effective.
- AWS Equivalent: DynamoDB (conceptually).
- Example: User session information.

---

# Azure Files

- Fully managed file shares.
- Accessible using SMB protocol.
- Can be mounted like a network drive.
- AWS Equivalent: Amazon EFS.
- Example: Shared application files.

---

# Managed Disks

- Persistent storage for Azure Virtual Machines.
- Automatically managed by Azure.
- Supports HDD and SSD.
- AWS Equivalent: Amazon EBS.
- Example: VM Operating System Disk.

---

# Storage Tiers

### Hot

- Frequently accessed data.
- Highest storage cost.
- Lowest access cost.

### Cool

- Infrequently accessed data.
- Lower storage cost.
- Higher access cost.

### Archive

- Rarely accessed data.
- Lowest storage cost.
- Highest retrieval time.
- AWS Equivalent:
    - Hot → S3 Standard
    - Cool → S3 Standard-IA
    - Archive → S3 Glacier

---

# Shared Access Signature (SAS)

- Generates temporary secure access to storage resources.
- Avoids sharing Storage Account keys.
- Can limit permissions and expiry time.
- AWS Equivalent: Pre-Signed URL.
- Example: Share a PDF download link valid for 30 minutes.
- Interview: Secure way to grant temporary access.

## Difference

|Service|Purpose|
|---|---|

|Queue|Messaging|
|Table|NoSQL Data|
