### Amazon CloudWatch

- CloudWatch - Monitoring service for AWS resources and applications.
- Collects metrics, logs and alarms.

---

### CloudWatch Logs

- Stores and monitors application and service logs.

---

### CloudWatch Metrics

- Measures resource performance.
- Examples - CPU Utilization, Memory, Network Traffic.

---

### CloudWatch Alarm

- Triggers notifications or actions when predefined conditions are met.

---

### AWS CloudTrail

- Records AWS account activities and API calls.
- Used for auditing and security.

---

### AWS CloudFormation

- Infrastructure as Code (IaC) service.
- Creates and manages AWS resources using templates.

---

### AWS CodeCommit

- Managed Git repository service.

---

### AWS CodeBuild

- Compiles source code and runs automated builds.

---

### AWS CodeDeploy

- Automates application deployment to AWS resources.

---

### AWS CodePipeline

- Automates CI/CD pipelines.
- Integrates build, test and deployment stages.

---

### CI/CD

- CI (Continuous Integration) - Frequently integrates code changes.
- CD (Continuous Delivery/Deployment) - Automates application delivery.

---

### Infrastructure as Code (IaC)

- Manages infrastructure using configuration files instead of manual setup.

---

### Benefits

- Automated deployments.
- Faster releases.
- Improved monitoring.
- Better reliability.
- Consistent infrastructure.
